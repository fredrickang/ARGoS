# Excel-ready data for the three-case figures

Generated by `scripts/fig_three_cases.py --export` (paper reward = `band_*.csv`/`avg_dmr.csv`;
v2 reward = `v2_*.csv`). The experiment uses a **fixed 10 s window, 2000 windows** (adaptive
window off), so every case has the same window axis — the first column is the **window index**,
and all cases are aligned directly (no interpolation).

## X-axis at window intervals
These are line/area charts over the `window` category axis (1 … 2000). To show ticks every,
say, 200 windows: double-click the horizontal axis → Axis Options → Labels →
**Interval between labels = Specify interval unit = 200** (and Major gridline interval = 200).

## band_util.csv / band_dmr.csv — shaded band + mean line
Per case three columns: `<case>_lo`, `<case>_band` (= hi − lo), `<case>_mean`.

Build the band in Excel (one chart per case, or overlay):
1. Select `window`, `<case>_lo`, `<case>_band` → insert a **Stacked Area** chart.
2. Click the **lo** series → Format → Fill = **No fill** (invisible base).
3. Click the **band** series → Fill = a solid color at ~75% transparency (the shaded band).
4. Right-click chart → Select Data → add `<case>_mean` → change its series type to **Line**.
   (Insert → Combo chart makes steps 1 & 4 one action.)

## avg_dmr.csv — cumulative miss ratio vs Theorem-1 bound
`<case>_avg` = cumulative mean of M_k (missed / max-releasable, the bounded quantity).
`bound_case2_lam1` (α=0.1, λ₁=1), `bound_case3_lam05` (α=0.1, λ₁=0.5), `bound_case1_a0` (α=0),
with bound(K) = α + (λ₁ − r_min + γB)/(γK) at window K. Plot all as **Line**. The bound columns
start large (≈21 at K=1) and decay like 1/K, so set the y-axis max to ~0.5–1.0 to see the
realized curves; each `_avg` stays under its bound.
